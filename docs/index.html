Beamline Live demonstration

Run a draw. Then try to rig it.

Beamline publishes a signed, hash-chained beacon pulse every minute. Anything drawn from a pulse can be recomputed by anyone afterwards — which is what turns “trust us, it was random” into something a sceptic can check. The ten pulses on this page are real, produced by the code in this repository and signed with Ed25519. Everything below runs in your browser: no server call, no account, nothing to install.

01

Run a draw

Name your draw, pick the pulse that will fix it, and press the button. The winners are derived from the pulse hash by rejection sampling — the same algorithm the server runs, reimplemented here in about forty lines.

Two things worth trying. Run the same draw twice: the winners are identical, because the pulse is fixed and the derivation is deterministic. Then nudge the tag by one character: the winners are completely different, and there is no way to steer them anywhere in particular. In a real draw the tag is published before the pulse exists, so the operator gets exactly one attempt.

Space weather

Each pulse records digests of the physical inputs that fed it. The NOAA space-weather readings are public and timestamped, so a sceptic can confirm the pulse was not computed before those measurements existed. They are credited zero bits of secret entropy — they are provenance, not secrecy.

03

The chain closes the back door

One pulse alone proves only that a result follows from it. Each pulse also hashes the one before, so history is a chain. Rewrite round 5 below and the pulse after it stops fitting; repair that one and the break moves to the next. The chain does not make rewriting history impossible — it makes it impossible to do quietly.

04

What this is actually for

Not key material. Randomness fetched over a network is randomness someone else could have observed, and your operating system already gives you a better answer for free. Beamline is for the case where the randomness has to be defensible to somebody who assumes you cheated.

Giveaways and raffles

A creator picks three winners from 4,820 entrants and the audience believes it, because they can recompute it themselves.

Compliance sampling

An auditor pulls 200 transactions from four million and can show the sample was not chosen to look clean.

Allocation and seeding

Limited inventory, product drops, launch slots, tournament brackets — anywhere the organiser has a favourite.

Provably fair games

Commit to a seed hash, let the pulse supply the public entropy, let the player verify the drop.

The honest limit. The chain proves ordering and tamper-evidence. It does not, by itself, prove an operator never withheld a pulse it disliked and waited for the next one. Publishing the tag in advance closes that gap on the customer's side; anchoring pulse hashes to an external append-only log closes it on the operator's side, and is on the roadmap. The NIST Randomness Beacon states the same limitation, and naming it is worth more than hiding it.
